## Features

- Sign in to WaterSmart using an email address and password.
- Download historical hourly water usage through the RealTimeChart API.
- Preserve downloaded readings and the last completed hour across restarts.
- Refresh `sensor.watersmart_<account_number>_water_usage_hourly` every 30 minutes.
- Import historical readings into Home Assistant recorder statistics.
- Automatically renew expired sessions and prompt for updated credentials when required.

## Installation

Requires Home Assistant **2026.10 or newer**.

Add `sivagorrepati/ha-watersmart` to HACS as a custom **Integration** repository,
or extract `watersmart.zip` into your Home Assistant configuration directory.
Restart Home Assistant and add **WaterSmart** under Settings → Devices & services.

## Validation and limitations

Validated with automated tests and the Milpitas HAR capture. Live authentication
has not been tested. Supports the active portal account; MFA, CAPTCHA, and account
switching are not supported.
